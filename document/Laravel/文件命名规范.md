### 文件命名规范

Laravel 遵循 **约定优于配置** 的原则，按照以下规则组织文件，可以让你更好地使用框架提供的自动化功能。

---

### 核心概念
- **命名空间**： 文件所在的目录结构直接映射到其命名空间。
- **类名**： 使用 **大驼峰式（PascalCase）**，如 `UserController`。
- **文件名**： 通常与类名完全一致（`.php` 扩展名除外）。
- **其他文件**： 如配置文件、视图、CSS等，通常使用 **蛇形命名法（snake_case）**。

---

### 主要目录与文件规则

#### 1. `app/` 目录 (应用核心代码)
这是你编写业务逻辑的主要位置。

| 文件类型 | 目录 | 命名规则 | 示例 |
| :--- | :--- | :--- | :--- |
| **模型 (Model)** | `app/Models/` | 单数、大驼峰 | `User.php`, `Product.php` |
| **控制器 (Controller)** | `app/Http/Controllers/` | 大驼峰，以 `Controller` 结尾 | `UserController.php`, `Admin/UserController.php` |
| **中间件 (Middleware)** | `app/Http/Middleware/` | 大驼峰，以 `Middleware` 结尾（可选） | `Authenticate.php`, `CheckAdmin.php` |
| **服务提供者 (Provider)** | `app/Providers/` | 大驼峰，以 `ServiceProvider` 结尾 | `AppServiceProvider.php`, `AuthServiceProvider.php` |
| **事件 (Event)** | `app/Events/` | 大驼峰，以 `Event` 结尾（可选） | `OrderShipped.php` |
| **监听器 (Listener)** | `app/Listeners/` | 大驼峰，以 `Listener` 结尾（可选） | `SendShipmentNotification.php` |
| **任务/作业 (Job)** | `app/Jobs/` | 大驼峰，以 `Job` 结尾（可选） | `ProcessPodcast.php` |
| **邮件 (Mailable)** | `app/Mail/` | 大驼峰，以 `Mail` 结尾（可选） | `OrderShipped.php` |
| **通知 (Notification)** | `app/Notifications/` | 大驼峰，以 `Notification` 结尾（可选） | `InvoicePaid.php` |
| **控制台命令 (Command)** | `app/Console/Commands/` | 大驼峰，以 `Command` 结尾（可选） | `SendEmails.php` |
| **表单请求 (Form Request)** | `app/Http/Requests/` | 大驼峰，以 `Request` 结尾 | `StoreUserRequest.php` |
| **数据仓库/服务类** | `app/Services/`, `app/Repositories/` 等 | 自定义目录，大驼峰 | `PaymentService.php`, `UserRepository.php` |

#### 2. `database/` 目录 (数据库相关)
| 文件类型 | 目录 | 命名规则 | 示例 |
| :--- | :--- | :--- | :--- |
| **迁移文件 (Migration)** | `database/migrations/` | `YYYY_MM_DD_HHMMSS_描述性名称.php` (蛇形) | `2024_01_01_000001_create_users_table.php` |
| **数据填充器 (Seeder)** | `database/seeders/` | 大驼峰，以 `Seeder` 结尾 | `DatabaseSeeder.php`, `UserSeeder.php` |
| **模型工厂 (Factory)** | `database/factories/` | 大驼峰，以 `Factory` 结尾 | `UserFactory.php` |

#### 3. `resources/` 目录 (前端资源)
| 文件类型 | 目录 | 命名规则 | 示例 |
| :--- | :--- | :--- | :--- |
| **视图 (Blade)** | `resources/views/` | 蛇形或kebab-case，`.blade.php` 结尾 | `welcome.blade.php`, `users/show.blade.php` |
| **JS 文件** | `resources/js/` | 通常小驼峰或kebab-case | `app.js`, `bootstrap.js` |
| **CSS/SASS 文件** | `resources/css/` 或 `resources/sass/` | 通常kebab-case | `app.css`, `_variables.scss` |

#### 4. `config/` 目录 (配置文件)
| 文件类型 | 目录 | 命名规则 | 示例 |
| :--- | :--- | :--- | :--- |
| **配置文件** | `config/` | 蛇形， `.php` 结尾 | `app.php`, `database.php`, `cache.php` |

#### 5. `routes/` 目录 (路由文件)
| 文件类型 | 目录 | 命名规则 | 示例 |
| :--- | :--- | :--- | :--- |
| **路由文件** | `routes/` | 蛇形， `.php` 结尾 | `web.php`, `api.php`, `console.php` |

#### 6. `tests/` 目录 (测试文件)
| 文件类型 | 目录 | 命名规则 | 示例 |
| :--- | :--- | :--- | :--- |
| **单元测试 (Unit)** | `tests/Unit/` | 大驼峰，以 `Test` 结尾 | `UserTest.php` |
| **功能测试 (Feature)** | `tests/Feature/` | 大驼峰，以 `Test` 结尾 | `LoginTest.php` |

---

### 关键 Artisan 命令与自动生成
使用 `php artisan make:` 命令创建文件时，会自动遵循上述规则：

```bash
# 自动生成到对应目录，并应用正确命名
php artisan make:controller UserController
php artisan make:model Product
php artisan make:migration create_products_table
php artisan make:seeder UserSeeder
php artisan make:test UserTest
php artisan make:request StoreUserRequest
php artisan make:middleware CheckAdmin
```

### 总结与最佳实践
1.  **遵循约定**： 尽可能使用 Artisan 命令生成文件，保证结构和命名正确。
2.  **保持一致性**： 在自定义目录（如 `Services`）中，团队内部应保持统一的命名规范。
3.  **清晰明了**： 命名应能清晰表达文件或类的职责（如 `SendWelcomeEmailJob`）。
4.  **子目录组织**： 对于大型项目，可以使用子目录更好地组织代码（如 `Controllers/Admin/`， `Models/Traits/`）。

遵循这些规则，你的 Laravel 项目将结构清晰，易于维护，并能充分利用框架提供的便利功能。
