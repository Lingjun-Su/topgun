# 常用指令
Laravel 的核心命令行工具是 **Artisan**。为了方便你快速查找，我根据功能整理了以下常用指令：

| 功能分类 | 常用指令 | 作用描述 |
| :--- | :--- | :--- |
| **🧰 开发与代码生成** | `php artisan make:model ModelName` | 生成 Eloquent 模型。<br>常用参数：`-m` 同时生成迁移文件；`-c` 同时生成控制器。 |
| | `php artisan make:controller ControllerName` | 生成控制器。<br>常用参数：`--resource` 生成资源控制器。 |
| | `php artisan make:migration CreateTableName` | 生成数据库迁移文件。 |
| | `php artisan make:seeder SeederName` | 生成数据填充器。 |
| | `php artisan make:middleware MiddlewareName` | 生成中间件。 |
| | `php artisan make:request FormRequestName` | 生成表单请求类。 |
| **🗄️ 数据库操作** | `php artisan migrate` | 运行所有未执行的迁移。<br>常用参数：`--seed` 同时运行数据填充。 |
| | `php artisan migrate:rollback` | 回滚上一次的迁移操作。 |
| | `php artisan migrate:refresh` | 回滚并重新运行所有迁移。<br>常用参数：`--seed` 同时重新填充数据。 |
| | `php artisan migrate:status` | 查看每项迁移的运行状态。 |
| | `php artisan db:seed` | 运行数据填充器。<br>常用参数：`--class=SeederName` 指定单个填充器。 |
| **⚡ 缓存与优化** | `php artisan cache:clear` | 清除应用缓存。 |
| | `php artisan config:clear` | 清除已缓存的配置。 |
| | `php artisan route:clear` | 清除已缓存的路由。 |
| | `php artisan view:clear` | 清除已编译的视图文件。 |
| | `php artisan optimize` | 缓存框架引导文件、配置和路由，以提升性能。 |
| **🚀 项目运行与维护** | `php artisan serve` | 启动本地开发服务器。<br>常用参数：`--host`、`--port` 指定主机和端口。 |
| | `php artisan down` | 开启“维护模式”。<br>常用参数：`--retry=60` 告知浏览器重试时间。 |
| | `php artisan up` | 关闭“维护模式”。 |
| | `php artisan storage:link` | 创建 `public/storage` 到 `storage/app/public` 的符号链接。 |
| | `php artisan key:generate` | 生成应用的加密密钥（`.env` 中的 `APP_KEY`）。 |
| **📬 队列** | `php artisan queue:work` | 启动队列处理器，开始处理队列任务。<br>常用参数：`--daemon` 以守护进程模式运行；`--tries=3` 任务失败后重试次数。 |
| | `php artisan queue:failed` | 列出所有失败的队列任务。 |
| | `php artisan queue:retry all` | 重试所有失败的队列任务。 |

### 💡 使用小贴士

1.  **查看所有指令**：任何时候输入 `php artisan list` 可以查看所有可用指令。
2.  **查看指令帮助**：使用 `php artisan help 指令名称` 可以查看具体指令的详细参数说明。
3.  **自定义指令**：你可以使用 `php artisan make:command CommandName` 来创建自己的 Artisan 指令。
4.  **任务调度**：通过 `php artisan schedule:run` 可以执行定义在 `App\Console\Kernel` 中的计划任务，通常需要配置系统 Cron 每分钟自动执行此命令。

如果你想知道其中某个指令更详细的用法，或者想了解特定场景（如测试、事件等）的指令，我可以为你做进一步介绍。
