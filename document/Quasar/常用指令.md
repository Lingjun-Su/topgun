# 常用指令
理解您正在整理Quasar框架的“指令”，为了避免混淆，这里先明确两个核心概念：

1.  **命令行工具指令 (CLI Commands)**：这是您通过终端或命令提示符运行的管理项目、构建应用的命令，通常以 `quasar` 开头。
2.  **Vue/Quasar指令 (Vue Directives)**：这是在Vue组件模板中以 `v-` 前缀使用的特殊标记（如 `v-ripple`），用于控制DOM行为。

根据您之前的提问模式，您可能更想了解**Quasar CLI的常用命令行指令**，用于项目的创建、开发和构建。以下是这些核心命令的整理：

### 💻 Quasar CLI 核心命令速查

| 命令 | 作用与常用参数 | 示例与说明 |
| :--- | :--- | :--- |
| **`quasar create`** | **创建一个新的Quasar项目**。 | `quasar create my-project`  |
| **`quasar dev`** | **启动本地开发服务器**。支持指定模式（`-m`）、主题（`-t`）、端口（`-p`）。 | `quasar dev` <br> `quasar dev -m pwa -t ios -p 8080`  |
| **`quasar build`** | **构建用于生产环境的应用**。同样可指定模式和主题。 | `quasar build` <br> `quasar build -m cordova -T android`  |
| **`quasar ext`** | **管理Quasar的扩展（插件）**。 | `quasar ext add @quasar/icon-set`  |
| **`quasar new`** | **快速生成项目文件**。需指定类型和名称。 | `quasar new page AboutUs` <br> `quasar new layout MainLayout` <br> `quasar new boot axios`  |

### 🧩 Vue/Quasar 指令 (Vue Directives)
这类指令需要在项目的 `quasar.conf.js` 文件中**手动引入**才能使用。常用的有：
*   `v-ripple`：为元素添加水波纹点击效果。
*   `v-scroll`：监听滚动事件。
*   `v-touch-pan`, `v-touch-swipe`：监听触摸手势。

引入示例：
```javascript
// quasar.conf.js
framework: {
  directives: ['Ripple', 'TouchSwipe']
}
```

### 🛠️ 其他常用工具与函数
此外，Quasar还提供了一系列组合式函数和工具，它们以 `import` 形式在JavaScript代码中使用：
*   **组合式函数**：如 `useQuasar()` (获取全局`$q`对象) 和 `useDialogPluginComponent()` (创建自定义对话框)。
*   **实用工具**：如 `morph()` (DOM元素变形动画)、`debounce()` (防抖函数)等。

简单总结：**管理项目用CLI命令（`quasar build`），增强组件功能用Vue指令（`v-ripple`），在脚本逻辑中则使用组合式函数和工具（`useQuasar()`）。**
