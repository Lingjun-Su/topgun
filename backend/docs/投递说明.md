# 后端程序员 · 工作区说明（架构师投递）

依据 `032-角色工作目录与访问边界`，你只在本目录 `backend/doc/` 与业务代码 `backend/` 内作业，**不得**向上或横向访问项目顶层、`frontend/`、`doc/` 等目录。

## 你可见/可写目录

- ✅ 可读写：`backend/`（业务代码）、`backend/doc/回单/`、`backend/doc/工作日志/`
- 👁 只读：`backend/doc/`（本目录，架构师投递：工单·规范·数据库·接口·需求摘要）
- ⛔ 禁止：`frontend/`、`doc/`（含协同/规范/需求设计等）项目顶层

## 作业约定

1. **无工单+规范不开工**：一切以架构师下发的任务单为准，任务单注明「按 XX 规范实施」。
2. 认领任务：将任务单 `状态` 置为 `DOING`；完成自检后再置 `DONE`/交回单。
3. 涉及数据库时，任务单会明确 `库/表/字段变更` 与迁移/初始化脚本要求。
4. 产出**程序回单**到 `backend/doc/回单/回单-<任务号>.md`，结果仅 `completed` / `needs_change`。
5. 维护工作日志到 `backend/doc/工作日志/后端.md`（按 033，会话/阶段粒度追加、只增不改）。
6. 不修改任务单内容；任务单内容修改只归架构师。
