# 开发规范目录

本目录是**全部代码规则的唯一权威源**，由代码大管家维护，随时按需补充。其余任何目录中的规则副本都以本目录为准。

## 我作为规则源的下发方式

项目所在子目录没有权限向上访问本目录，因此当规则新增或变更时，由大管家将本目录的相应文档**同步推送到每个相关项目**的 `规范/` 子目录中。各项目不要在本地直接改规范，改动应回到本目录提出，统一在这里定稿后再下发。

每次规则变更须满足：

1. 修改本目录下对应文档；
2. 在下方变更日志追加一条记录并升级版本；
3. 将更新后的文档复制到所有相关项目的 `规范/` 副本；
4. 明确变更范围（新增 / 修改 / 废弃）供项目团队知悉。

## 技术栈覆盖现状

目前主题项目以 **Laravel + Quasar2 + SQL Server** 为主，少部分为 **微信小程序**，故先建立上述规则。未来若纳入其他语言（如测试服务器可能涉及的脚本语言），在本目录新增对应编号文档，再做下发。
