# 021 · 项目注册

适用范围：新增项目纳入管理体系时的登记规范，供大管家在 `项目表.md` 建立台账使用。

## 注册单字段

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| 项目代号 | 全局唯一缩写，小写 kebab | `wc-orders` |
| 项目名称 | 业务名称 | 订单中心 |
| 技术栈 | 落地选型 | `Laravel 11 · Quasar2 · SQL Server` |
| 仓库目录 | 物理/仓库位置 | `项目/wc-orders` |
| 负责人 / 联系方式 | 资源对接人 | — |
| 接口清单范围 | 负责的契约前缀 | `/api/v1/orders` |
| 数据源 | 库连接、接口、外部服务 | `orders_db` |
| 端口 / 环境变量 | 分配的端口与变量键 | `8101 · ORDERS_*` |
| 第三方凭证 | 关联密钥与到期日 | — |
| 登记日期 / 版本 | 审计与追溯 | — |

## 登记流程

1. 在 `项目表.md` 追加一条记录，填写全部字段。
2. 在 `项目/` 下建立以「项目代号」命名的子目录。
3. 下发 `开发规范/` 全部文档到该项目的 `规范/` 子目录。
4. 分配端口并回填 `测试服务器/端口分配表.md`；涉及第三方凭证则在 `资源与凭证/` 登记元信息。

## 触发与静默

无新增项目、无规则变更时，本体系保持静态，不产出任何例行更新。
