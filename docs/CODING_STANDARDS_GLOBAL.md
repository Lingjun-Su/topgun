# TopGun 项目全局编码规范

---

## 1. 技术栈约束

### 1.1 版本升级策略

- **禁止**无评估跨大版本升级
- 升级必须包含：影响分析、回归清单、回滚方案
- **必须**提交锁文件（`composer.lock`, `package-lock.json`）

### 1.2 技术栈概览

| 分类 | 技术 | 版本 |
|------|------|------|
| 后端框架 | Laravel | 12.x |
| 前端框架 | Vue | 3.5.x |
| UI组件库 | Quasar | 2.16.x |
| 数据库 | SQL Server | - |

---

## 2. 编码风格规范

### 2.1 通用规则

| 规则 | 规范 |
|------|------|
| 编码 | UTF-8 |
| 换行符 | LF |
| 后端缩进 | 4 空格 |
| 前端缩进 | 2 空格 |
| 最大行宽 | 100 字符 |
| 注释原则 | 解释"为什么"，不解释"做什么" |

### 2.2 路由命名规范

| 类型 | 规则 | 示例 |
|------|------|------|
| REST 资源 | 复数 kebab-case | `/api/v1/users` |
| 动作路由 | 动词开头 camelCase | `changePassword` |
| 版本前缀 | `v1`, `v2` | `/api/v1/products` |

### 2.3 禁止项

```php
// 后端禁止
dd($data);           // 使用 Log 替代
var_dump($var);      // 使用 Log 替代
exit();              // 使用异常处理替代
```

```javascript
// 前端禁止
console.log(data);   // 使用日志库或注释掉
console.debug(data); // 使用日志库或注释掉
```

---

## 3. 数据库命名规范

| 类型 | 规则 | 示例 |
|------|------|------|
| 表名 | 复数 snake_case | `master_contracts` |
| 字段名 | snake_case | `contract_no`, `org_a_id` |
| 主键 | `id` | - |
| 外键 | `{表名单数}_id` | `user_id`, `master_id` |
| 时间戳 | `created_at`, `updated_at`, `deleted_at` | - |

---

## 4. 安全规范（通用）

| 规则 | 说明 |
|------|------|
| 敏感配置 | 禁止硬编码密钥，使用 `.env` 配置 |
| 审计日志 | 关键操作必须记录审计日志 |
| 输入验证 | 所有输入必须经过验证 |

---

## 5. PR 最低门槛

| 检查项 | 要求 |
|--------|------|
| 分层不越界 | Controller 不写业务逻辑 |
| 无调试代码 | 删除 `dd()`、`console.log()` |
| 无硬编码 | 敏感配置使用环境变量 |
| 回归测试 | 关键链路有测试或回归说明 |
| 无重复代码 | 不新增重复状态定义 |
| 文件大小 | 单个文件不超过 500 行 |
