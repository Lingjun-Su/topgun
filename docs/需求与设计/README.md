# 需求与设计

本目录存放需求说明、方案设计与原型说明。当前为导入基线，以下需求概览依据现有代码（后端路由 / 控制器、前端页面）整理，后续细化时在此目录补充正式需求文档。

## 需求概览（导入基线）

### 1. 基础数据管理

- **运营商（Carrier）**：运营商档案维护。
- **业务（Business）**：业务类型维护。
- **业务产品（Product / ProductProvince）**：产品及产品-省份配置。
- **数据字典（Dictionary）**：系统级字典项维护。
- **省市区（Area / Region）**：地区数据（公开接口）。

### 2. 组织与人员

- **组织架构（Organization）**：公司 / 部门 / 岗位树形管理。
- **公司（Company）**：拓耕集团下属公司列表。
- **部门（Department）**：按组织维护。
- **岗位（Position）**：按部门 / 组织维护。
- **员工（Employee）**：员工档案与任职记录（EmployeeAssignment），支持离职 / 复职。

### 3. 渠道与订单

- **渠道配置（ThirdChannel）**：第三方渠道及渠道下产品配置同步。
- **全域订单（QuanyuOrders）**：订单列表、待同步、重试推送、批量重试、取消 / 退订。
- **数据中转（ForwardOrder）**：中转记录查询与重试。
- **回调日志（CallbackLog）**：第三方回调记录。
- **推送统计（PushStats）**：推送概览统计。
- **产品订单（ProductOrder）**：订单列表 / 详情 / 导出 / 批量推送 / 状态统计。
- **全链路追踪（Trace）**：按 traceId 查询订单全链路。

### 4. 合同管理

- **框架合同（MasterContract）**：新增 / 提交 / 撤回 / 审核 / 废止 / 到期 / 条款维护。
- **合同分割**：框架合同分割为执行合同。
- **执行合同（ExecutionContract）**：列表 / 明细 / 修改 / 审核流转。
- **合同审核日志（MasterContractLog）**：审核过程留痕。

### 5. 报表与统计

- 产品订单销量简报、月度图表、销售饼图、今日数据、业务统计。

### 6. 系统与运维

- 用户与认证（注册 / 登录 / 修改密码 / 登出，Sanctum）。
- 死信队列（FailedJob）：失败任务查看与重试。
- 第三方渠道接口（v2）：订单接收 / 修改 / 验证码提交 / 回调接收 / 转发查询，签名鉴权 + 限流。
