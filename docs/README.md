# 文档中心（doc/）

唐贝管理系统（topgun）的文档导航。目录结构遵循 `规范/022-项目目录与文档规范.md`。

## 目录导航

| 目录 | 内容 | 入口 |
| --- | --- | --- |
| `需求与设计/` | 需求说明、方案、原型说明 | [需求说明](./需求与设计/README.md) |
| `接口文档/` | 接口契约说明与 API 概览 | [接口概览](./接口文档/README.md) |
| `数据库/` | 表结构说明与 ER 图 | [数据库说明](./数据库/README.md) |
| `协同/` | Agent 协同通道：任务单 / 程序回单 / 测试回单 / 归档 | [协同通道](./协同/README.md) |
| `里程碑/` | 各定版版本的里程碑快照（记忆检查点） | [里程碑](./里程碑/README.md) |
| `会议与决策/` | 关键决策与技术评审记录 | [会议与决策](./会议与决策/README.md) |
| `规范/` | 大管家下发的最新规则副本（只读） | [规范副本](./规范/README.md) |
| `pkg/` | 项目知识图谱（PKG）：实体/关系/索引/ADR/现状基线 | [PKG 入口](./pkg/README.md) |

## 使用约定

- `规范/` 为只读副本，规则以 `开发规范/` 为准，改动回到规则库定稿后由大管家同步下发。
- Agent 之间不直接对话，一切信息交换经由 `协同/` 下的固定通道文档完成。
- 版本定版后，在 `里程碑/` 生成 `MILESTONE-<版本>.md` 快照，作为后续会话的记忆检查点。
