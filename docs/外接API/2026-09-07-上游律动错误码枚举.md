# 上游 A · 律动 · 错误码枚举

> 来源：上游 A 方「律动」提供的错误码字典（官方）。
> 本表用于统一映射上游返回的 `error_code`（如 `C4005`），在统计页展示可读中文文案。
> 权威定义：`backend/app/Enums/MobileErrorCode.php`。

## 枚举分组总览

| 系列 | 类别 | 码段 |
| --- | --- | --- |
| E 系列 | 业务错误 | 00000、E0001、E0003、E0005 |
| 400 系列 | 管控错误 | 40001 ~ 40008 |
| S 系列 | 用户状态 | S0101、S0202、S0205、S0303 |

> 补充说明：`E0005` 语义为「短信验证码不正确，请重新获取」或「办理业务失败（通常会附带 400xx 子错误码）」。
> `40005` 的非订购时间段管控为「22点至次日7点」。

## 详细错误码对照表

### E 系列 · 业务错误

| 错误码 | 含义 |
| --- | --- |
| `00000` | 成功 |
| `E0001` | 订单状态异常 |
| `E0003` | 验证码有误 |
| `E0005` | 短信验证码不正确，请重新获取！ / 办理业务失败（通常会附带 400xx 子错误码） |

### 400 系列 · 管控错误

| 错误码 | 含义 |
| --- | --- |
| `40001` | 单一管控应用订购套餐个数限制 |
| `40002` | 多管控应用限制订购涉及的应用个数 |
| `40003` | 处于号码管控库（黑名单或者退订期用户） |
| `40004` | 业务处于超限管控中（日/月发展量超阈值） |
| `40005` | 非订购时间段管控（22点至次日7点） |
| `40006` | 业务处于24小时退订率超限管控中（40%） |
| `40007` | 用户不下发验证码了 |
| `40008` | 移动系统大数据黑名单校验 |

### S 系列 · 用户状态

| 错误码 | 含义 |
| --- | --- |
| `S0101` | 号码有误 |
| `S0202` | 非移动用户 |
| `S0205` | 年龄不符合要求 |
| `S0303` | 请求频繁 |

## 落地约定

- 新出现的上游错误码，需回填本表 + `MobileErrorCode.php`，保持两侧同步。
- 统计接口在返回 `error_code` 时附 `error_msg`（可读含义），前端直接展示。
- 未知错误码（未收录）仍原样返回 `error_code`，`error_msg` 置为「其他错误」。
- **不同 A 的错误码体系相互独立**：统计表以 `target_pid`（A）为维度分组，前端按「A → 系列 → 具体错误码」分层展示。当前 `MobileErrorCode` 收录的是律动一家的错误码；接入其他 A（如上家）时，需为该 A 维护独立的错误码字典，并按 `target_pid` 路由到对应枚举，不得与律动字典混用。
- **未收录错误码统一归「其他」**：从 `forward_error` 提取出的错误码若不在 `MobileErrorCode` 枚举内，接口将其归入「其他」系列并原样展示；确无错误码可归的失败单回填为 `OTHER` 归入「其他」。保证每个失败都能归入某一系列或「其他」，与每日失败汇总数一致。
- **400 子错误码细分**：主码 `E0005`（办理业务失败）会附带 `400xx` 子错误码，聚合时从 `forward_error` 提取第一个 400 子码存入 `sub_error_code`，接口与页面将主码与 400 子码并列展示，子码含义复用 400 系列枚举。
