## 2. 编码风格规范

### 2.1 JavaScript/TypeScript 命名规范

| 类型 | 规则 | 示例 |
|------|------|------|
| 变量 | camelCase | `contractList` |
| 函数 | camelCase | `fetchContracts` |
| 常量 | UPPER_SNAKE_CASE | `API_BASE_URL` |
| 组件 | PascalCase | `MasterContractForm.vue` |
| Composable | `use` + PascalCase | `useWorkflow.js` |
| 文件 | kebab-case | `master-contract.js` |

### 2.2 通用规则

| 规则 | 规范 |
|------|------|
| 编码 | UTF-8 |
| 换行符 | LF |
| 缩进 | 2 空格 |
| 最大行宽 | 100 字符 |

## 3. 架构与模块划分规范

### 3.1 前端分层架构

```
┌─────────────────────────────────────────────────────┐
│  pages/                # 页面层：页面编排              │
├─────────────────────────────────────────────────────┤
│  components/           # 组件层：可复用 UI 组件       │
├─────────────────────────────────────────────────────┤
│  api/                  # API 层：请求封装             │
├─────────────────────────────────────────────────────┤
│  stores/               # 状态层：全局状态管理          │
├─────────────────────────────────────────────────────┤
│  boot/                 # 启动层：全局初始化            │
└─────────────────────────────────────────────────────┘
```

### 3.2 各层职责

| 层级 | 职责 | 禁止做的事 |
|------|------|-----------|
| **pages/** | 页面编排，不堆业务细节 | 编写可复用组件 |
| **components/** | 可复用 UI 组件 | 直接调用 API、管理全局状态 |
| **api/** | 请求封装，统一错误处理 | 编写 UI 提示逻辑 |
| **stores/** | 全局状态管理 | 拼接后端 URL、处理 DOM |
| **boot/** | 插件初始化（axios、guard） | 处理业务逻辑 |

### 3.3 模块划分规范

项目按业务领域划分模块：

| 模块 | 目录结构 | 说明 |
|------|---------|------|
| **合同管理** | `pages/contract/` | 框架合同、执行合同 |
| **产品订单** | `pages/productOrders/` | 订单管理、报表 |
| **组织架构** | `pages/` | 组织、部门、员工管理 |

## 4. 性能规范

| 规则 | 说明 |
|------|------|
| 组件懒加载 | 使用动态 import 延迟加载组件 |
| 资源压缩 | 生产环境启用 JS/CSS 压缩 |
| 图片优化 | 使用合适的图片格式和尺寸 |
| 避免内存泄漏 | 及时清理事件监听器和定时器 |

---

## 5. 安全规范

| 规则 | 说明 |
|------|------|
| Token 存储 | 统一使用 `auth_token` 作为存储键 |
| 请求拦截 | 使用 Axios 拦截器统一处理认证 |
| XSS 防护 | 使用 Vue 自动转义，手动处理危险内容 |
